## 2. Objeto de la entrega

Se entrega la plataforma para la recepción, seguimiento y gestión interna de solicitudes de ejercicio de derechos de protección de datos personales, conforme al alcance acordado por las partes.

## 4. Alcance entregado

- Portal público para presentar solicitudes y consultar su estado.
- Catálogo de derechos LOPDP: acceso, rectificación y actualización, eliminación, oposición, portabilidad y suspensión.
- Referencia y códigos de seguimiento por correo, cuando SMTP esté configurado.
- Gestión de expedientes, asignación, revisión, aclaraciones, extensiones, evidencias y plazos.
- Resoluciones con causales aplicables según el tipo de resolución.
- Comunicaciones, cola de correo, auditoría, reportes, roles y MFA.
- Instancias aisladas por empresa con base de datos y personalización independiente.

## 5. Documentación entregada

- Manual operativo para la empresa.
- README técnico del repositorio.
- Guía Docker por empresa.
- Guía de despacho de correo y checklist de publicación.
- Ficha técnica confidencial de cada empresa.

## 6. Responsabilidades posteriores a la entrega

La empresa receptora se responsabiliza de:

- Designar usuarios, DPD y responsables del tratamiento.
- Mantener actualizados los datos de contacto, avisos legales y usuarios.
- Configurar y mantener el correo SMTP institucional.
- Atender las solicitudes dentro de los plazos y con el criterio jurídico aplicable.
- Solicitar soporte técnico ante incidentes o cambios de infraestructura.

El equipo implementador se responsabiliza de entregar la plataforma y documentación indicadas en esta acta, conforme al alcance acordado.
