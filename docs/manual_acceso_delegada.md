# Manual de acceso para la delegada

Este manual aplica a las cuentas administrativas creadas para la delegada de
proteccion de datos en las cuatro instancias del portal.

La contraseña debe entregarse por un canal seguro y no debe guardarse en correos
sin cifrado, chats públicos o documentos compartidos sin control de acceso.

## 2. Primer ingreso

1. Abra la URL correspondiente a la empresa.
2. Ingrese el correo de usuario y la contraseña entregada.
3. El sistema solicitará configurar la verificación en dos pasos.
4. Escanee el código QR con una aplicación autenticadora.
5. Ingrese el código de 6 dígitos generado por la aplicación.
6. Guarde los códigos de recuperación que se muestran al final.

Aplicaciones autenticadoras recomendadas:

- Microsoft Authenticator.
- Google Authenticator.
- 1Password, Bitwarden u otro gestor con soporte TOTP.

## 3. Códigos de recuperación

Después de activar la verificación en dos pasos, el sistema mostrará códigos de
recuperación. Cada código sirve una sola vez y permite ingresar si no se tiene
acceso temporal a la aplicación autenticadora.

Recomendaciones:

- Guardarlos en un gestor de contraseñas.
- No enviarlos por correo.
- No fotografiarlos en dispositivos compartidos.
- Solicitar regeneración si se sospecha que fueron expuestos.

## 4. Ingresos posteriores

Para ingresar después del primer acceso:

1. Abra la URL de la empresa.
2. Ingrese correo y contraseña.
3. Ingrese el código de 6 dígitos de la aplicación autenticadora.

Si no dispone del autenticador, utilice un código de recuperación en el mismo
campo de verificación.

## 5. Validaciones iniciales sugeridas

Al ingresar a cada instancia, revise:

- Datos institucionales en `Configuración`.
- Razón social, RUC, dirección y teléfono.
- Correo de privacidad y canal del DPD.
- Logo, colores y favicon de la empresa.
- Documentos publicados en `Avisos`.
- Que la página principal muestre los 4 derechos públicos: Acceso,
  Rectificación, Eliminación y Oposición.

## 6. Seguridad operativa

- No compartir usuario ni contraseña.
- Cerrar sesión al terminar, especialmente en equipos compartidos.
- Reportar inmediatamente pérdida del celular con autenticador.
- Solicitar cambio de contraseña si hubo exposición o sospecha de acceso no
  autorizado.
- No descargar información personal fuera de los fines autorizados.

## 7. Recuperación de acceso

Si la delegada pierde acceso:

1. Verificar si conserva un código de recuperación.
2. Si no lo conserva, solicitar a un administrador el restablecimiento de MFA o
   contraseña.
3. Después del restablecimiento, volver a configurar la verificación en dos
   pasos y guardar nuevos códigos de recuperación.
