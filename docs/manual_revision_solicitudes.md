# Manual de revision de solicitudes

Este manual describe el flujo recomendado para revisar y atender solicitudes de
ejercicio de derechos en el portal de privacidad.

## 1. Acceso al panel

1. Ingrese a la URL administrativa de la empresa.
2. Inicie sesion con el usuario asignado.
3. Complete la verificacion en dos pasos.
4. Desde el menu, abra `Expedientes`.

URLs administrativas:

| Empresa | URL |
| --- | --- |
| VINESA | `https://privacidad.vinesa.com.ec/accounts/login/` |
| VINLITORAL | `https://privacidad.vinlitoral.com.ec/accounts/login/` |
| PLUSBRAND | `https://privacidad.plusbrand.com.ec/accounts/login/` |
| SERVMULTIMARC | `https://privacidad.laguarda.com.ec/accounts/login/` |

## 2. Listado de expedientes

La pantalla `Expedientes` muestra:

- Total de expedientes visibles.
- Solicitudes en gestion.
- Expedientes sin asignar.
- Expedientes finalizados.

Use los filtros para ubicar solicitudes por:

- Referencia del expediente.
- Derecho solicitado.
- Estado.
- Estado de asignacion.

Para abrir una solicitud, haga clic en la referencia del expediente o en el
boton de flecha de la fila.

## 3. Revision inicial del expediente

En el detalle del expediente revise primero la seccion `Resumen`:

- Derecho solicitado.
- Estado actual.
- Estado de identidad.
- Canal de ingreso.
- Fecha de recepcion.
- Fecha limite.
- Responsable asignado.
- Si existe extension aplicada.

Luego revise:

- `Identidad`: datos del titular y, si aplica, representante.
- `Solicitud`: descripcion del requerimiento.
- `Aclaraciones`: solicitudes de informacion adicional y respuestas recibidas.
- `Historial`: trazabilidad de estados.

Si los datos personales no estan visibles, el perfil actual no tiene permiso
para ver informacion sensible o la identidad aun no fue validada.

## 4. Verificacion de identidad y evidencias

Desde el expediente, ingrese a `Evidencias`.

Revise:

- Documentos adjuntos.
- Tipo de archivo.
- Estado del escaneo.
- Historial de verificaciones.

Cuando corresponda, registre la verificacion:

1. Abra `Registrar verificacion de identidad`.
2. Seleccione el metodo de verificacion.
3. Seleccione el resultado.
4. Agregue notas de validacion.
5. Guarde la verificacion.

Use notas objetivas y breves. Evite incluir informacion sensible innecesaria.

## 5. Inicio de revision

Si el expediente esta listo para gestion:

1. Abra el expediente.
2. En `Acciones del expediente`, pulse `Iniciar revision`.
3. Confirme que el estado cambie en la linea de tiempo.

Este paso deja constancia de que la solicitud ya entro a analisis interno.

## 6. Solicitar aclaracion

Use `Solicitar aclaracion` cuando la solicitud sea incompleta o falte
informacion para atenderla.

Recomendaciones:

- Explique exactamente que informacion falta.
- Indique documentos requeridos si aplica.
- Evite pedir informacion que no sea necesaria para resolver el caso.
- Revise el efecto de la aclaracion sobre los plazos.

Cuando el titular responda, registre la respuesta desde la seccion
`Aclaraciones` con `Registrar respuesta`.

## 7. Comunicaciones

Desde el expediente puede abrir `Comunicaciones`.

En esta pantalla puede:

- Revisar mensajes vinculados al expediente.
- Registrar una comunicacion entrante.
- Registrar un correo saliente.
- Marcar si la comunicacion sera visible para el titular.

Tipos comunes de comunicacion:

- Acuse de recepcion.
- Solicitud de informacion.
- Respuesta.
- Informacion de reclamo.
- Aviso de extension.

Mientras el correo SMTP no este configurado, el sistema puede registrar o poner
en cola comunicaciones, pero el envio real de correo dependera de la
configuracion pendiente.

## 8. Aplicar extension

Use `Aplicar extension` solo cuando la normativa y el caso lo permitan.

Antes de aplicarla:

- Verifique la fecha limite actual.
- Justifique la necesidad de extension.
- Registre la comunicacion correspondiente al titular.

## 9. Registrar resolucion

Cuando el analisis este completo:

1. Abra el expediente.
2. Seleccione `Registrar resolucion`.
3. Complete el tipo de resolucion y los campos requeridos.
4. Guarde la resolucion.
5. Registre o revise la comunicacion de respuesta al titular.

La resolucion debe ser clara, proporcional y coherente con el derecho
solicitado.

## 10. Marcar como respondida y cerrar

Despues de emitir o registrar la respuesta:

1. Use `Marcar como respondida` cuando la respuesta al titular ya fue registrada.
2. Use `Cerrar expediente` cuando no existan acciones pendientes.
3. Revise la linea de tiempo para confirmar la trazabilidad.

No cierre un expediente si:

- Falta verificar identidad.
- Hay una aclaracion pendiente.
- No se registro respuesta o resolucion.
- Existe evidencia pendiente de revision.

## 11. Reportes y seguimiento

Use los reportes para revisar:

- Solicitudes por derecho.
- Expedientes finalizados.
- Expedientes en proceso.
- Pendientes.
- Porcentaje de finalizacion.

Tambien puede exportar la informacion disponible a CSV cuando sea necesario
para control interno.

## 12. Buenas practicas

- Trabaje siempre desde la instancia correcta de la empresa.
- No descargue documentos si no es necesario.
- No comparta capturas con datos personales.
- Use las comunicaciones del sistema para mantener trazabilidad.
- No modifique datos institucionales sin autorizacion.
- Revise plazos antes de dejar un expediente sin accion.
- Cierre sesion al terminar.

## 13. Escalamiento

Escalar al administrador o responsable cuando:

- No pueda acceder al expediente.
- El MFA o la contrasena falle.
- Un documento adjunto no pueda descargarse.
- El sistema muestre errores al guardar.
- Existan dudas sobre la procedencia juridica de una respuesta.
- El caso requiera confirmacion legal antes de responder.
